# 소모품 교체 준수 판정기 (consumable-replacement-tracker)

세방전지 창원공장 극판(연속도장) 라인 설비 소모품의 **예상 교체일**과 **실제 교체일**을
비교하여 **조기 / 정시 / 지연 / 미교체**를 판정하는 Python 프로그램입니다.

- 두 교체이력 소스(생산팀 엑셀, 전산 SMES 설비이상조회)를 병합하고
  소모품 교체주기 마스터와 대조해 호기별·등급별 준수율을 산출합니다.
- 결과는 `output/result_YYYYMMDD.xlsx` 6개 시트로 출력됩니다.

---

## 1. 실행법

```bash
# 가상환경 + 의존성
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

# 실행 (실데이터 예시)
python -m src.main \
  --date   2026-10-22 \
  --prod   data/01.xlsx \
  --smes   data/smes/ \
  --master data/03.xlsx

# 샘플 데이터로 바로 돌려보기
python -m src.main \
  --date   2026-10-22 \
  --prod   data_sample/01_생산팀_교체이력_샘플.xlsx \
  --smes   data_sample/02_전산_교체이력_샘플.xls \
  --master data_sample/03_소모품_교체주기_마스터.xlsx
```

| 인자 | 설명 |
|---|---|
| `--date` | 분석 기준일(YYYY-MM-DD). "미교체(초과 진행중)" 판정과 초과일수 계산의 기준 |
| `--prod` | 01 생산팀 교체이력 `.xlsx` (시트 `2601이후`) |
| `--smes` | 02 SMES `.xls` **파일 또는 폴더** (월별 복수 파일 가능, 공백으로 여러 개 나열 가능) |
| `--master` | 03 소모품 교체주기 마스터 `.xlsx` (시트 `교체주기_기준`) |
| `--config` | (선택) config 디렉터리. 기본 `config` |
| `--out` | (선택) 출력 디렉터리. 기본 `output` |

- Python 3.11 호환으로 작성되었습니다. (개발/검증은 3.11 이상 환경에서 수행)
- 실데이터는 `data/`(gitignore), 샘플은 `data_sample/` 에 둡니다.

---

## 2. 입력 3종 형식

### 입력 1 — 03 소모품 교체주기 마스터 (`.xlsx`)
- 시트 **`교체주기_기준`** 만 사용 (나머지 3개 시트 무시).
- 1행 헤더, 2~35행 = 34개 항목. 키 = **(공정(설비), 교체 항목)**.
- **교체 주기(일)의 의미**: "3년 이력 **최소주기 × 70% 가혹조건**"으로 산출된 값입니다.
  즉 **늦어도 이 주기 안에는 교체해야 하는 상한(최소 교체 일정)** 입니다.
  → 예상일보다 **조기** 교체는 (과잉교체 모니터링 대상이긴 하나) **준수**로 집계합니다.
- 호기 구분이 없는 6개 공정(혼합기, 도장, 디바이더, 순간 건조기(F/D), 극판 적재기, 극판 적재 로봇)은
  `config/equipment_alias.csv` 의 4개 호기(CP1/CP2/PP1/PP2)로 전개합니다.
  그 외(주조기, 언코일러, PUNCHER)는 호기 전개 없이 SMES 단독 소스로 처리합니다.

### 입력 2 — 01 생산팀 교체이력 (`.xlsx`)
- 시트 **`2601이후`** 만 사용.
- 2행 설비 블록 헤더(CP1=C열, CP2=K열, PP1=S열, PP2=AA열, 각 8컬럼 폭),
  3행 서브헤더, 4행부터 데이터.
- A열 날짜 **3형식 혼재**(datetime / 문자열 `'260401'` / 정수 `260909`)를 모두 파싱.
  날짜는 '주' 행에만 있어 forward-fill 하며, '야' 행도 같은 생산일로 귀속(교대 기준 08:00).
- 교체 정보는 각 블록 **"부동 내용" · "기타"** 셀의 자유 텍스트. 줄바꿈/쉼표/슬래시로 분리 후 키워드 매칭.
- `형명 교체` / `금형 교체` 같은 금형·형명 변경은 소모품 교체가 **아니므로 제외**.
  `연도지교체` / `스풀교체` 숫자 컬럼은 일상 소모품이라 마스터 대상이 아니므로 **무시**.

### 입력 3 — 02 전산 SMES 설비이상조회 (`.xls`, 월별 복수 파일)
- `--smes` 는 폴더 또는 파일 목록을 받아 모두 읽어 세로로 합치고,
  **(발생일자, 설비코드, 신고시간, 라인정지내용)** 기준 중복 행을 제거합니다.
- 각 파일: 시트 1개, 1행 헤더, **2행(총부동시간 합계행) 제외**, **상태=`오신고` 행 제외**.
- **발생일자**(`'2026-10-01'`)를 생산일로 사용(이미 08:00 교대 기준 귀속됨). 신고시간은 날짜 계산에 쓰지 않음.
- **작업자 컬럼은 읽지 않고 버립니다(개인정보).**
- 설비명/라인코드 → 호기 변환은 `config/equipment_alias.csv`. 매핑 없는 설비는 설비명을 그대로 둠(타 라인).
- 교체 판정은 `라인정지내용 + 최종상태 + 의견` 세 텍스트를 합쳐 동일 키워드로 매칭.

> **구 `.xls` 읽기**: `xlrd>=2.0` 사용. (xlrd 2.0은 `.xls` 전용이며 `.xlsx` 는 읽지 않으므로,
> SMES 폴더에서는 `*.xls` 만 수집합니다.)

## 3. 판정 규칙

### 기준점(baseline)
- 항목×호기별로 **`analysis_start`(기본 2026-09-01) 이후 첫 교체일**을 기준점으로 삼고,
  그 회차는 판정 **`기준설정`**(조기/정시/지연 제외)으로 표시합니다.
- `analysis_start` 이후 교체 기록이 전혀 없으면 **`기록없음`** 1행만 남기고 예상일·편차는 비웁니다.
  (임의로 기준일을 추정하지 않습니다.)
- `config/baseline_override.csv` 에 값을 넣으면 그 날짜가 데이터상 첫 교체일보다 **우선**합니다.

### 예상일 · 판정
- **예상 교체일 = 직전 실제 교체일 + 교체 주기(일)**
- **허용오차**는 등급별 값(`config/rules.yaml`). **★ 가정값 — 확정 전 ★** (A:2, B:3, C:5)

| 판정 | 조건 | 집계 |
|---|---|---|
| **조기** | 실제일 < 예상일 − 허용오차 | 준수 (과잉교체 모니터링용 정보성) |
| **정시** | \|실제일 − 예상일\| ≤ 허용오차 | 준수 |
| **지연** | 실제일 > 예상일 + 허용오차 | 미준수 |
| **미교체** | `--date` 가 예상일+허용오차를 지났는데 이후 교체 기록 없음 | 미준수. 초과일수 = `--date` − 예상일 |
| **기준설정 / 기록없음** | — | 판정 제외 |

- **편차_일 = 실제일 − 예상일** (음수=조기, 양수=지연)
- **준수율(%) = (조기 + 정시) ÷ (조기 + 정시 + 지연 + 미교체) × 100.** 기준설정·기록없음은 분모 제외.
- 주기(일)가 `analysis_start`~`--date` 일수보다 길면 2회차가 아직 올 수 없으므로,
  요약 시트에 **"판정 가능 항목 수 / 전체 항목 수"** 를 별도 표기합니다.
- 날짜 파싱 실패/빈 행은 삭제하지 않고 **"파싱오류"** 시트로 보냅니다.

## 4. 출력 (`output/result_YYYYMMDD.xlsx`)

| 시트 | 내용 |
|---|---|
| **요약** | 호기별·등급별 6종 판정 건수, 준수율, 1소스(확인필요) 비율, "판정 가능/전체 항목 수", 데이터 커버리지(출처별 시작~종료일, 종료일 7일↑ 차이 시 경고) |
| **상세** | 호기·공정·항목·등급·주기·직전/예상/실제 교체일·편차·판정·출처·확인필요·원문. 판정별 배경색(지연·미교체 빨강, 조기 노랑, 정시 녹색, 기준설정 회색, 기록없음 회색글자) |
| **미교체현황** | `--date` 기준 예상일 초과 항목만, 초과일수 내림차순 |
| **미매칭** | `교체` 포함이나 마스터 어느 항목에도 매칭 안 된 조각 (마스터 추가 검토용) |
| **파싱오류** | 날짜 파싱 실패 등 보류 행 |
| **다음예정** | 다음 예상 교체일 오름차순(미래 일정표). 기록없음 항목은 하단에 "기준일 미설정"으로 별도 나열 |

## 5. 설정(config) 수정 방법

모든 컬럼명·키워드·허용오차·분석 시작일·교대 기준은 `config/` 에 있으며 코드에 하드코딩하지 않습니다.

### `config/rules.yaml`
분석 시작일, 교대 기준 시각, 등급별 허용오차(가정값), 병합 허용일수, 커버리지 경고 임계,
키워드 매칭 방식(`match_mode: token_and`, `require_token: 교체`), 금형/형명 제외 마커.

### `config/equipment_alias.csv`
설비 표기 ↔ 호기 매핑. 컬럼: `standard_line, prod_label, smes_equipment, smes_linecode`.
**새 SMES 설비명이 추가되면** 해당 행을 추가하세요(미매핑 설비는 설비명이 그대로 호기 자리에 남습니다).

### `config/part_keywords.csv` — 키워드 추가 절차
컬럼: `master_item, include_tokens, exclude_keywords, 검토필요`

- **매칭 방식(token_and)**: `include_tokens` 의 한 조각이 `+` 로 묶이면 **모두 포함(AND)**,
  `|` 로 나뉘면 **대안(OR)**. 공통으로 `교체`(require_token)가 반드시 포함돼야 합니다.
  예) `칼날|러그커터|러그+커터` → `(칼날) OR (러그커터) OR (러그 AND 커터)`, 그리고 모두 `+교체`.
  비교는 **공백 무시**이므로 `디바이더 좌측 칼날 2개 교체` 도 `칼날`+`교체` 로 매칭됩니다.
- **우선순위**: 한 조각이 여러 항목에 매칭되면 **토큰 수가 많은(더 구체적인)** 항목이 우선.
  예) `호퍼 베어링 교체`(호퍼+베어링) 가 `호퍼 교체`(호퍼) 보다 우선 → 호퍼 교체 vs 호퍼 베어링 교체 구분.
- **exclude_keywords**: `|` 중 하나라도 조각에 있으면 그 항목 매칭에서 제외.
- **검토필요=1**: 현장 표기 미확인(마스터 항목명 기반 추정). 실데이터의 "미매칭" 시트를 보고 보강하세요.

> **표기 보강 워크플로**: 실행 후 `output/..xlsx` 의 **미매칭** 시트를 열어 `교체` 는 포함하지만
> 잡히지 않은 현장 표기를 확인 → 해당 표기의 핵심 토큰을 적절한 `master_item` 행의
> `include_tokens` 에 `|` 로 추가 → 재실행.

### `config/baseline_override.csv`
(선택) 기준일 수동 지정. 컬럼: `standard_line, master_item, baseline_date`. 기본은 비어 있습니다.

## 7. 가정·한계 (중요)

- **허용오차(A:2/B:3/C:5)는 가정값이며 확정 전입니다.** 현장 합의 후 `rules.yaml` 에서 조정하세요.
- **교체 주기(일)는 "최소주기×70%" 상한**이라, 실제 교체가 더 잦으면 대부분 **조기**로 집계됩니다
  (과잉교체 모니터링 신호). 조기 과다는 주기값 재검토 또는 설비 이상 신호일 수 있습니다.
- `part_keywords.csv` 34항목 중 일부는 현장 표기 미확인(`검토필요=1`) 상태입니다.
- SMES 샘플은 10월분만 존재(9월 공백)하므로, 9월 교체 건은 생산팀 단독 소스입니다.
  요약 시트의 커버리지 경고를 확인하세요.
